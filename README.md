# Tima's Roast — HTML

A specialty coffee shop landing page built as a single-page site to showcase the menu, story, and location of a fictional Islamabad coffee roaster. Built with semantic HTML5, CSS3, and vanilla JavaScript.

## How to Run the Project

Live Link: https://fatimabscs4932-dotcom.github.io/HTML/

Alternatively, to run it locally:
1. Clone or download this repository.
2. Open the project folder and double-click the `index.html` file.
3. The site will open automatically in your default web browser.

Note: For the best experience, use a modern browser like Google Chrome or Mozilla Firefox.

## Project Structure

- `index.html` — Page markup and content
- `style.css` — Styling and responsive layout
- `script.js` — Mobile navigation toggle

## Tech Stack

- HTML5 (semantic sections, nav, footer)
- CSS3 (custom properties, grid, media queries)
- Vanilla JavaScript (DOM manipulation)
- Google Fonts (Cormorant Garamond + Inter)

## Features

- Fixed navigation with smooth-scroll anchor links
- Hero, menu grid, story, and contact sections
- Responsive layout for mobile and desktop
- Live menu with pricing
