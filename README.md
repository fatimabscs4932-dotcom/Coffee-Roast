# Tima's Roast

A specialty coffee shop landing page for a fictional Islamabad-based roaster, built to showcase the menu, brand story, and store details in a single responsive page. It exists as a clean, editorial-style front-end project using HTML5, CSS3, and vanilla JavaScript.

## How to Run the Project

You can view the live project directly here: https://fatimabscs4932-dotcom.github.io/Coffee-Roast/

Alternatively, to run it locally:
1. Clone or download this repository.
2. Open the project folder and double-click the `index.html` file.
3. The site will open automatically in your default web browser.

Note: For the best experience, use a modern browser like Google Chrome or Mozilla Firefox.

## Project Structure

- `index.html` - Page markup and content
- `style.css` - Styling, layout, and responsive design
- `script.js` - Mobile navigation toggle

## Tech Stack

- HTML5 (semantic sections, navigation, footer)
- CSS3 (custom properties, CSS Grid, media queries)
- Vanilla JavaScript (DOM manipulation for the hamburger menu)
- Google Fonts (Cormorant Garamond and Inter)

## Features

- Fixed navigation bar with smooth-scroll anchor links
- Two-column hero section with image and "Since 2019" badge
- Three-column feature strip highlighting the brand values
- Two-column menu grid with item descriptions and pricing
- About section with brand story and quality checklist
- Contact section with address, phone, email, and opening hours
- Fully responsive layout with a mobile hamburger menu
- Coffee-inspired color system using CSS variables
